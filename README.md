## 🛠️ Tecnologias do Site

- **HTML5 + CSS3 + JavaScript** — estrutura e interatividade
- **Animação CSS (floating bubble particles)** — efeito de bolhas flutuantes no fundo, implementado com `@keyframes` e elementos em `position: absolute` que sobem com `translateY`, criando um ambiente lúdico e temático
- **Design responsivo** — adaptação para desktop e mobile
